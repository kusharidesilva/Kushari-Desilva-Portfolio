# Kushari Desilva Portfolio

This is a [Next.js](https://nextjs.org) project built with the App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the portfolio by modifying files inside the `src` folder. The page auto-updates as you edit the files.

## Static Export

This project is configured as a static frontend project for Cloudflare Pages.

```txt
Build command: npm run build
Output directory: out
```

The `out` folder is generated automatically when you run:

```bash
npm run build
```
